# SeaDex - Hackathon Project - Solo
Webpage: https://meloburr.github.io/seadex/

## Inspiration
Millions of people know that there are endangered marine animals; however, they don't know the causes, the problems, or how to help. This inspired me to create a virtual dictionary so people can easily learn about these causes and how to help them.
## What it does
SeaDex gives people a virtual dictionary to help learn about the causes of endangered marine animals and how to help them.
## How we built it
I built it by first creating a rough design of the webpage using HTML, CSS, and JavaScript. Then, I added the content and the dictionary, followed by a fun little puzzle so people can quiz themselves once they think they've learned the causes and how to help.
## Challenges we ran into
I had many challenges. These ranged from fixing misplaced text, font formatting, and CSS bugs, to making sure the layout, animations, and interactive features were not glitchy or off the screen. For the content, I spent a huge amount of time researching 1,460 entries of endangered marine animal data about the problems they face and how to help them.
## Accomplishments that I'm proud of
- Built a searchable dictionary featuring **1,460 animal entries**, each with detailed problems, solutions, and actionable steps.
- Clearly separated **species-specific advice** from general **group-based advice** so users get accurate guidance.
- Added custom **search, filters, sorting, and page navigation** to make browsing large amounts of data fast and easy.
- Created an **interactive ocean conservation puzzle** to help users test what they learned.
- Built a **progress-saving checklist** right in the browser so users can track how they help over time.
## What we learned
- Marine animals deal with different threats like pollution, fishing gear, warming water, and losing their habitats.
- Protecting the areas where they feed and breed helps them recover.
- Everyday choices really do make a difference, along with community effort and better laws.
- An animal can be doing fine in most of the world but still be in danger in specific areas.
- Every species is different, so the way we help has to match what that specific animal needs.
## What's next for SeaDex
- Grow the dictionary with more species-specific conservation guides.
- Bring SeaDex to more students, families, and classrooms.
- Create more ocean puzzles and learning activities.
